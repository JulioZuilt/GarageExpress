GarageExpress

App movil para la gestion de inventario de un taller automotriz.
Proyecto de la asignatura DSY1105.

Que hace la app:
- Inicio de sesion con usuarios guardados en la base de datos
- Registro de nuevos usuarios (admin o asistente)
- Lista de productos con buscador y filtro por categoria
- Agregar, editar y eliminar productos (solo admin)
- Registrar movimientos de inventario (venta, reposicion, etc) que actualizan el stock
- Lectura de codigo QR con la camara al agregar un producto

Tecnologias usadas:
- Kotlin
- Jetpack Compose
- Material 3
- Room (base de datos local)
- Arquitectura MVVM

Cuentas de prueba:
- admin / 123
- asistente / 123

Como abrir el proyecto:
1. Abrir Android Studio
2. File - Open y elegir la carpeta GarageExpress
3. Esperar a que termine la sincronizacion de Gradle
4. Ejecutar en un emulador o telefono con camara
